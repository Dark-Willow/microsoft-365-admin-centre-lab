# Microsoft 365 User Support Workflow

This document summarises the Microsoft 365 user support workflow practised in this lab.

## Workflow

```text
User or requester reports Microsoft 365 issue
        ↓
Support ticket is logged
        ↓
User account is checked in Active users
        ↓
Licence, sign-in status, groups, or mailbox settings are reviewed
        ↓
Required action is completed
        ↓
User or requester confirms access
        ↓
Ticket is resolved and documented
