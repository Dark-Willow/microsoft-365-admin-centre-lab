# Ticket 05 — Outlook Mailbox Issue

## Ticket Summary

User reports an Outlook mailbox issue.

## User / Requester

IT Support One

## Issue Type

Incident

## Priority

Medium

## Scenario

The user reports that Outlook is not working as expected. Possible symptoms may include emails not syncing, mailbox access problems, or issues with sending and receiving email.

## Troubleshooting / Support Actions

- Checked the user account in Microsoft 365 Admin Centre
- Reviewed the Mail tab for the user
- Checked mailbox storage
- Reviewed mailbox permissions
- Reviewed email apps
- Reviewed email forwarding settings
- Confirmed whether the user had the correct licence and mailbox access

## Resolution

The mailbox settings were reviewed in Microsoft 365 Admin Centre. Further troubleshooting would depend on the specific Outlook error or user symptom.

## Skills Practised

- Outlook support awareness
- Mailbox settings review
- Mailbox storage check
- Email forwarding review
- User mail settings
- Service desk troubleshooting documentation
