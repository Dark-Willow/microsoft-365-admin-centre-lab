# Ticket 04 — Shared Mailbox Access

## Ticket Summary

User needs access to the IT Support shared mailbox.

## User / Requester

IT Support One

## Issue Type

Service Request

## Priority

Medium

## Scenario

The user needs access to the IT Support shared mailbox so they can receive and manage support-related emails.

## Troubleshooting / Support Actions

- Created the IT Support Mailbox shared mailbox
- Opened the shared mailbox settings
- Added IT Support One as a member
- Reviewed shared mailbox details
- Checked mailbox settings such as members, permissions, forwarding, automatic replies, and email apps

## Resolution

The user was added to the IT Support shared mailbox. The mailbox settings were reviewed and documented.

## Skills Practised

- Shared mailbox management
- Mailbox membership
- Mailbox permissions awareness
- Microsoft 365 mail administration
- IT Support documentation
