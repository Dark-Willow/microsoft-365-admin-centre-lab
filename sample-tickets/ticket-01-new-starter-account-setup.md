# Ticket 01 — New Starter Account Setup

## Ticket Summary

A new starter requires a Microsoft 365 account before their first working day.

## User / Requester

HR Department

## Issue Type

Service Request

## Priority

Medium

## Scenario

HR has requested a new Microsoft 365 account for a new employee. The user needs access to Microsoft 365 services, email, and the correct department group.

## Troubleshooting / Support Actions

- Created a new Microsoft 365 user account
- Assigned a Microsoft 365 licence
- Required the user to change password at first sign-in
- Confirmed the user was created without administrator access
- Added the user to the correct department group
- Confirmed the account appeared in Active users

## Resolution

The new starter Microsoft 365 account was created successfully. The user was assigned the correct licence and added to the relevant group.

## Skills Practised

- User account creation
- Licence assignment
- Group membership
- Least privilege
- IT Support documentation
