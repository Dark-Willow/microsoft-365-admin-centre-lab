# Ticket 03 — Block Sign-in for Security Review

## Ticket Summary

A user account needs sign-in blocked temporarily for security reasons.

## User / Requester

Finance User One

## Issue Type

Security / Account Access

## Priority

High

## Scenario

The account required temporary sign-in blocking as part of an account access review.

## Troubleshooting / Support Actions

- Located the user in Microsoft 365 Admin Centre
- Opened the user account from Active users
- Blocked the user from signing in
- Confirmed sign-in was blocked
- Later restored sign-in access after review
- Confirmed the account was unblocked

## Resolution

The user account was temporarily blocked from signing in and later unblocked after review.

## Skills Practised

- Sign-in blocking
- Sign-in unblocking
- Account security
- Identity access management
- Microsoft 365 Admin Centre navigation
