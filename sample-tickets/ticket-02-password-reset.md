# Ticket 02 — Password Reset

## Ticket Summary

User cannot sign in and requires a password reset.

## User / Requester

HR User One

## Issue Type

Incident

## Priority

High

## Scenario

The user reported that they were unable to sign in to their Microsoft 365 account and needed their password reset.

## Troubleshooting / Support Actions

- Located the user in Microsoft 365 Admin Centre
- Opened the user account from Active users
- Reset the user password
- Confirmed the password reset was completed
- Ensured the temporary password was not exposed in documentation
- Advised that the user should change the password at next sign-in

## Resolution

The user's password was reset successfully. The user can attempt sign-in again using the temporary password and change it when prompted.
