# Lab 04 — Groups and Access Management

## Objective

The objective of this lab is to practise basic group and access management in the Microsoft 365 Admin Centre.

This lab focuses on creating a Microsoft 365 group, creating a security group, adding users to groups, and reviewing group membership.

## What I Learned

In this lab, I learned how Microsoft 365 groups and security groups can be used to manage users and access.

Microsoft 365 groups can support collaboration and shared access for departments or teams, while security groups can be used to manage access permissions for groups of users.

I also learned that managing access through groups is better than assigning permissions to users one by one because it is easier to maintain and review.

## IT Support Relevance

Groups are commonly used in workplace IT environments to manage access to resources, departments, mailboxes, applications, and shared services.

Service desk teams may be asked to add users to groups, remove users from groups, check group membership, or confirm whether a user has the correct access.

Understanding group management helps support new starter requests, department changes, access requests, and leaver processes.

## Security+ Connection

This lab connects to Security+ concepts such as identity and access management, least privilege, and access control.

Using groups helps control access more consistently and reduces the risk of giving users unnecessary permissions.

## AZ-104 Connection

This lab connects to Azure and Microsoft cloud administration because Microsoft 365 groups and security groups are linked to Microsoft Entra ID.

Understanding group membership and access management is useful for later Azure administration, RBAC, and cloud identity management.
