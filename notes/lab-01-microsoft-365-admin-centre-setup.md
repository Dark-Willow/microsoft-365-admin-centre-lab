# Lab 01 — Microsoft 365 Admin Centre Setup

## Objective

The objective of this lab is to set up access to the Microsoft 365 Admin Centre and confirm that the tenant is ready for basic IT Support administration tasks.

This lab focuses on accessing the Admin Centre, reviewing the main dashboard, and opening the Active users page where user accounts can be managed.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft 365 Admin Centre |
| Tenant Type | Microsoft 365 Business |
| Lab Focus | Admin Centre access and user management area |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Tasks Completed

- Created a Microsoft 365 business tenant for lab practice
- Signed in to the Microsoft 365 Admin Centre
- Confirmed access to the Admin Centre dashboard
- Located the main navigation menu
- Opened the Users section
- Opened the Active users page
- Captured screenshots for documentation

## What I Learned

In this lab, I learned how to access the Microsoft 365 Admin Centre using a business admin account.

I also learned that the Active users page is a key area for IT Support tasks such as creating users, managing accounts, resetting passwords, assigning licences, and reviewing user details.

This setup will be used for later labs involving user management, password resets, sign-in management, groups, licences, mailbox basics, and Microsoft 365 support scenarios.

## IT Support Relevance

Microsoft 365 is commonly used in workplace environments, and service desk teams often support users with account access, password issues, Outlook problems, licence assignment, and mailbox access.

Understanding the Admin Centre helps build practical skills for IT Support, Service Desk, and Microsoft 365 support roles.
