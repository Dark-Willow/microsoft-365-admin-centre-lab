# Lab 05 — Mailbox and Shared Mailbox Basics

## Objective

The objective of this lab is to practise basic mailbox and shared mailbox management in the Microsoft 365 Admin Centre.

This lab focuses on creating a shared mailbox, adding members, reviewing shared mailbox settings, and checking user mailbox settings.

| Component | Details |
|---|---|

| Tenant Type | Microsoft 365 Business |

## What I Learned

In this lab, I learned how shared mailboxes are used in Microsoft 365 to allow multiple users to access and manage email from a common mailbox.

I also learned how shared mailbox settings can include members, email forwarding, automatic replies, email apps, sent items, and mailbox permissions.

Reviewing the Mail tab for a user account also helped me understand where an IT Support technician can check mailbox storage, mailbox permissions, email apps, forwarding, and global address list visibility.

## IT Support Relevance

Shared mailboxes are commonly used by support teams, HR teams, finance teams, and other departments that need a shared email address.

In a workplace environment, service desk teams may be asked to add users to shared mailboxes, review mailbox access, check mailbox settings, troubleshoot access problems, and confirm whether a user has the correct mailbox permissions.

## Security+ Connection

This lab connects to access control and least privilege.

Shared mailbox access should only be given to users who need it. Reviewing mailbox membership and permissions helps reduce unnecessary access.

## AZ-104 Connection

This lab connects to Microsoft cloud administration because mailbox access, user identities, and permissions are managed through Microsoft 365 and Microsoft Entra ID-linked accounts.

Understanding mailbox access and user permissions helps build a foundation for later cloud identity and access management.
