# Lab 06 — Microsoft 365 Support Scenarios and Final Documentation

## Objective

The objective of this lab is to complete the Microsoft 365 Admin Centre project by documenting common Microsoft 365 support scenarios and the overall user support workflow.

This lab focuses on sample service desk tickets, workflow documentation, and final project documentation.

## Support Scenarios Documented

| Ticket | Scenario | Area Practised |
|---|---|---|
| Ticket 01 | New starter account setup | User creation, licence assignment, group membership |
| Ticket 02 | Password reset | Account access troubleshooting |
| Ticket 03 | Block sign-in for security review | Sign-in management and account security |
| Ticket 04 | Shared mailbox access | Shared mailbox membership and mailbox permissions |
| Ticket 05 | Outlook mailbox issue | Mail settings and Outlook support awareness |
