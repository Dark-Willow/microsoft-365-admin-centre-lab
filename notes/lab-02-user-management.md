# Lab 02 — User Management

## Objective

The objective of this lab is to practise basic user management in the Microsoft 365 Admin Centre.

This lab focuses on creating test users, assigning Microsoft 365 licences, confirming user account details, and ensuring users are created with standard user permissions instead of administrator access.

## What I Learned

In this lab, I learned how to create users in the Microsoft 365 Admin Centre and assign product licences during the account creation process.

I also learned that standard users should not be given administrator access unless there is a specific business need. This supports the principle of least privilege, where users only receive the access they need to do their work.

The user details page is useful for IT Support because it provides access to common account support actions such as resetting passwords, blocking sign-in, reviewing licences and apps, checking mail settings, reviewing group membership, and managing roles.

## IT Support Relevance

Creating and managing users is a common task for IT Support and Service Desk teams.

In a workplace environment, support teams may create accounts for new starters, update user details, assign licences, troubleshoot access issues, reset passwords, block sign-in for security reasons, and confirm that users have the correct Microsoft 365 access.

## Security+ Connection

This lab connects to basic security principles such as least privilege, account management, identity access, and user lifecycle management.

Creating standard users without administrator access helps reduce risk and supports secure account management.

## AZ-104 Connection

This lab connects to Azure and Microsoft cloud administration because Microsoft 365 users are linked to Microsoft Entra ID identities.

Understanding users, licences, roles, and groups in Microsoft 365 helps build a foundation for later Azure administration and identity management topics.
